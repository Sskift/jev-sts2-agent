## 实际修正

- 第 22 层曾因准备动作挤占后续出牌费用而停止。已在 `cffbb4a` 修复，核对 `pending=null` 后恢复同一局，随后正常赢下 Spiny Toad；[恢复证据](evidence/2026-09-21/run29-budget-recovery.json)保留独立记录。
- 原生 `StatusCard` 与静态图 `Status` 现归一到同一种公开意图。原先首只 Myte 的状态牌招式匹配为空，现在可以关联 Toxic → Bite → Suck。没有读取内部 move ID 或 RNG。
- 首回合原请求只有 Toxic 招式名，没有生成目的地、数量和 Toxic 卡牌完整规则。提取器现从已核对版本的具名招式中提取直接生成牌调用，并让规则检索沿怪物 → 生成牌 → 关键词关联。现有源码覆盖 14 个调用；三个符号数量仍为未知，分支、重复、目标、打断和手牌溢出未被假定为已模拟。未来可能生成的牌不会加入当前牌堆或合法动作。
- 把敌人生命的评估范围与我方受伤的不确定性分开。若所有范围分支都确认敌人存活、当前攻击量不变，生命范围不再抹掉独立的来袭伤害和结束生命。主结果同时列出条件生命、伤害和格挡范围；可能击杀、反伤、变化的攻击和未计算修正仍保持相应未知。

115 个行动图的既有状态、边和源文件哈希保持一致；游戏程序集哈希也与原固定版本相同。83 项相关检查通过。继续使用 Node.js 与本地 JSON，没有新增运行时依赖。
