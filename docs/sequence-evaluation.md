## 实现

`turn_sequence.mjs` 为能量预留、候选描述和完整方案提供共同的有序计算。已核实的升级费用／效果、属性药水、Setup Strike、Tender、Stomp 和 Whirlwind X 支付只作用于后续动作。它保留原观察，无法由整数预览确定的变化给出范围或未知，不把初始牌面当作未来常量。

抽牌、变形、回收选牌、新能力、未计算的下一张牌费用与自动出牌触发需要原生观察。计划在断点结束，不再声明使用已变形的旧卡或直接结束回合。单卡升级先绑定具体实例，可为以后回合升级，不强迫立即打出。

方案上下文增加消耗／保留的药水、未被已计算伤害使用的格挡和普通格挡重置时间。回合目标改为可修订的意图，战斗指令收敛为共同的比较维度，移除了按 Speed Potion、Stomp 等单独追加的战术提示。规则与策略选择仍分开，代码没有禁止零 X 攻击或强制某个药水顺序。

原生 v0.111.0 核对还补上 Cloak Clasp → Orichalcum → Plating 的结算先后、Tender 在显示计数为零时仍逐牌触发，以及 Frantic Escape 对 Sandpit 的顺序计数变化。静态规则来自[本地 Spire Codex 快照](../data/spire-codex/README.md)；[公开接口](https://spire-codex.com/developers)用于核对资料来源，精确时机以对应本机原生实现复核。未提交游戏二进制或反编译源码。没有新增运行时依赖。
