# 当前工作计划

更新：2026-09-21。本轮知识与回合规划的离线优化已完成；**不启动新对局**。三幕正式通关目标仍未完成。当前结果和限制见[知识与规划回归](knowledge-evaluation.md)。

## 本轮完成

1. 将五个角色的攻略整理为有来源、前提和代价的本地建议。实时模组事实、版本化规则、攻略建议和条件分析分层提供，每次只注入相关内容。
2. 从本机 v0.111.0 程序集静态提取现有目录的 115 个怪物行动图，区分固定后继、条件分支、随机权重、重复上限和冷却。只根据可见意图关联后续可能行动；14 个条目的初始条件未解析，保留缺口。
3. 从不同合法起手独立生成有序方案，保留原模型提案和局部替换。默认最多检查 4,096 个前缀、选取 64 个独立候选；合法首动作超过 64 个时保留各起手。候选覆盖与截断写入日志。完整方案或观察段都可参与比较。
4. 入围方案与原提案进行双向 A/B 比较，记录顺序分歧和并列，不把模型置信度当成正确率。每对方案直接给出完整描述；共享索引的压缩实验因收益小且观察到目标选择退化而撤回。
5. 方案区分永久战斗进展与复活小怪的暂时归零；未计算的死亡／复活触发不再产生确定的安全结论。补齐药水对下一张牌的观察断点。
6. 使用旧局面完成只读 Jev 回归，保存代码、schema、JSON 知识源和输入哈希；更新 README、架构和证据。在 `master` 提交并推送，不为本仓库开 PR。

## 评估边界

[本轮回归清单](../eval/knowledge-regression.json)中的第 19、24、26 局已经用于前几轮分析。文件名仍保留 `holdout`，但现在全部视为已暴露的回归样本，不能再声称是独立测试集。原始请求、响应、被撤回的中间版本结果均保留，没有发送游戏命令。

第 19 局第 4 回合最终两次都取得 19 点首领伤害，旧版两次都对 21 HP 的复活小怪造成 19 点伤害、没有击倒；两者同为 25 格挡。第 24、26 局的方案有变化，但尚不能证明更好。第 26 局仍没有在初始计划中选择免费抽牌，需要将其作为未解决的模型取舍问题记录，而非把所有变化称为改善。

195 项 Node 检查通过。四次最终回归的入围比较有 7/18 对在交换展示顺序后改变偏好；复杂样本的输入与请求成本也上升。这表明机制表达和候选空间有进展，但模型判断尚不稳定。不能声称已经穷尽全部优化、完成置信度校准或证明胜率提高。

## 后续阶段
