## 本局完成的修正

- **费用与伤害分开计算。** Stomp 的按攻击次数降费句曾被误判成伤害公式，抹掉多牌组合的确定伤害。修正后已知组合账目恢复，且实战五张牌按计划续接，Stomp 降至 0 费，后四步没有新增模型请求。[降费证据](evidence/2026-09-21/run33-discount-review.json)
- **待判断方案直接使用具名 JSON。** 普通字段和完整说明优先，单个完整判断装不下时才压缩。Boss 首回合回放从 Stomp 单卡改为 Peck → Stomp，已知伤害 51→63，但仍漏掉可达到 75 的第三张攻击。第 29 层另一个已检查局面从放弃剩余能量改为 Shrug It Off，双向比较一致。[表示证据](evidence/2026-09-21/run33-readable-plans.json)
- **抽牌等观察节点保留已知受击缺口。** 新增条件账目，列出已知前缀生命、格挡、当前攻击、未覆盖伤害、生命余额与剩余能量。抽牌后的完整结算仍未知；反伤、未知倒地效果或攻击数值变化也不会被强行算成确定值。这适用于观察节点，不是为某张牌预设策略。
